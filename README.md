# YouTube Playlist Length

A simple tool to calculate the total length of a YouTube playlist. Users need to paste only the **playlist ID** to get the total duration.

### 🌐 Live Demo

Access the tool here: [YouTube Playlist Length](https://shiva-prasad-sarkar.github.io/YouTube-Playlist-Length/)

---

## How to Use

1. Copy the playlist ID from the YouTube URL.  
   Example: From  
   `https://www.youtube.com/watch?v=ID0pE6BZOB8&list=PLKyFAP_ydM17VPOp58yPMBTWkG8__Kwg7&index=1`  
   extract the ID:  
   `PLKyFAP_ydM17VPOp58yPMBTWkG8__Kwg7&index=1`

2. Paste the playlist ID into the input field on the webpage.
3. Click "Calculate" to view the total length.
